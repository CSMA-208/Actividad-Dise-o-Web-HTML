# Blog sobre TWICE

Página web informativa sobre el grupo de K-pop TWICE: su historia, integrantes y evolución musical.

## 📁 Estructura del proyecto

```
proyecto/
├── index.html       # Archivo principal del blog
├── img/
│   └── TWICE.jpg     # Imagen del grupo
└── README.md         # Este archivo
```

> ⚠️ Asegúrate de que la imagen `TWICE.jpg` esté dentro de una carpeta llamada `img/`, ubicada en el mismo directorio que el archivo HTML. Si no la tienes, la imagen no se mostrará.

## 🖥️ Cómo visualizar la página

Tienes varias opciones para ver la página en tu navegador:

### Opción 1: Abrir directamente el archivo
1. Ubica el archivo HTML (por ejemplo `index.html`) en tu computador.
2. Haz doble clic sobre él.
3. Se abrirá automáticamente en tu navegador predeterminado (Chrome, Firefox, Edge, etc.).

### Opción 2: Abrir desde el navegador
1. Abre tu navegador (Chrome, Firefox, Edge, etc.).
2. Presiona `Ctrl + O` (Windows/Linux) o `Cmd + O` (Mac).
3. Busca y selecciona el archivo HTML del proyecto.

### Opción 3: Usar Visual Studio Code (recomendado para desarrollo)
1. Abre la carpeta del proyecto en VS Code.
2. Instala la extensión **Live Server** (si no la tienes).
3. Haz clic derecho sobre el archivo HTML.
4. Selecciona **"Open with Live Server"**.
5. La página se abrirá automáticamente en tu navegador y se actualizará cada vez que guardes cambios.

## ✅ Requisitos

- Un navegador web actualizado (Chrome, Firefox, Edge, Safari, etc.).
- No se necesita instalar ningún servidor ni programa adicional para visualizarla de forma básica.

## 📌 Notas

- El archivo utiliza etiquetas semánticas de HTML5 (`header`, `section`, `article`, `footer`).
- La tabla de la ficha técnica y las listas de integrantes están estructuradas siguiendo buenas prácticas de accesibilidad.
- Si realizas cambios en el HTML, guarda el archivo y recarga el navegador (`F5` o `Ctrl + R`) para ver las actualizaciones.
